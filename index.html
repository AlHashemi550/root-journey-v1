الدرس السادس: الصلاحيات وفحص النظام

الهدف هو الوصول لرتبة Root (التحكم المطلق).

أوامر Linux/Termux:

uname -a # فحص النواة
id # معرفة الصلاحيات
ls -la # عرض RWX

أوامر Windows:

tasklist # عرض العمليات
kill -9 [PID] # قتل العملية

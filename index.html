الدرس السادس - صفحة 1

الدرس السادس: الصلاحيات ومعركة الثغرات

بعد تجاوز الشبكة، تأتي معركة الصلاحيات (Permissions)؛ وهي التي تحدد من يملك التحكم ومن يبقى خارجاً.

1. دخول النظام (The Entry)

يبحث المخترق عن المنافذ (Ports) غير المحمية مثل:

  • FTP (21): لنقل الملفات.
  • SSH (22): للتحكم عن بعد.

2. رفع الصلاحيات (Privilege Escalation)

يسعى المخترق للتحول من "مستخدم عادي" إلى Root (في Linux) أو Admin (في Windows) للسيطرة الكاملة.

3. صلاحيات الملفات (RWX)

الرمزالمعنىالوظيفة
(R) Readقراءةعرض محتوى الملفات.
(W) Writeكتابةتعديل أو حذف الملفات.
(X) Executeتنفيذتشغيل الأكواد والبرامج.
الدرس السادس - صفحة 2

تابع الدرس السادس: ميكانيكا الفحص والاختراق

| طبقات النظام

ينقسم النظام لطبقتين: User Space و Kernel Space (قلب النظام). السيطرة على الـ Kernel تعني السيطرة على الجهاز بالكامل.

| أوامر الفحص في Linux

# معرفة إصدار النظام
uname -a

# معرفة المستخدم الحالي وصلاحياته
id

# عرض الملفات وصلاحيات الـ RWX
ls -la

| أوامر الفحص في Windows

# عرض العمليات النشطة (Process List)
tasklist

# إغلاق برنامج بالقوة (Kill)
taskkill /F /PID [رقم العملية]
# ملاحظة: إذا رفض النظام، فأنت لا تملك صلاحية Admin!
نصيحة تقنية: من يملك الـ Root يملك كل شيء. تأكد دائماً من تشفير "المفتاح الخاص" ووضعه في مكان آمن داخل النظام.
